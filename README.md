## 🚀 VPS Deployment

**Summary:**
<b>📦 Click to expand</b>

### Step 1: Update system
```bash
sudo apt-get update && sudo apt-get upgrade -y
```

### Step 2: Install packages
```bash
sudo apt-get install python3 python3-pip ffmpeg git screen curl -y
```

### Step 3: Node.js
```bash
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt-get install -y nodejs
```

### Step 4: Clone YOUR repo
```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO
cd YOUR_REPO
```

### Step 5: Screen + venv
```bash
screen
sudo apt-get install python3-venv -y
python3 -m venv venv
source venv/bin/activate
```

### Step 6: Install deps
```bash
pip3 install -U pip
pip3 install -U -r requirements.txt
```

### Step 7: Config
```bash
nano .env
```

Fill:
- `API_ID` / `API_HASH` → https://my.telegram.org
- `BOT_TOKEN` → @BotFather
- `MONGO_DB_URI` → MongoDB Atlas
- `OWNER_ID` → Your Telegram ID
- `STRING_SESSION` → @MUSKAN_STRINGBOT
- `LOG_GROUP_ID` → Log group (-100...)
- `SUPPORT_GROUP` / `SUPPORT_CHANNEL` → Your links
- `UPSTREAM_REPO` → Your GitHub repo URL

Save: `Ctrl+X` → `Y` → `Enter`

### Step 8: Start
```bash
python3 -m ShrutiMusic
```
or
```bash
bash start
```

Detach screen: `Ctrl+A` then `D`
